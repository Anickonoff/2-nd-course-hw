# Учебный проект "Мини-игры"
Целью учебного проекта являлось ознакомиться на практике с основами JavaScript (переменные, циклы, взаимодействие с пользователем, работа с DOM).
## Задание
1. Сверстать страницу согласно макету Figma.
2. Написать код игр на JS. Для взаимодействия с игроком использовать функции prompt() и alert().
   
   2.1. Игра "Угадай число". Сгенерировать число от 1 до 100. Предложить пользователю угадать число. Подсказывать: загаданное число больше или меньше введённого пользователем. Завершить игру, когда число будет угадано.

   2.2. Игра "Простая арифметика". Генерировать случайные задачи на сложение, вычитание, умножение и деление. Запросить у пользователя ответ. Проверить правильность ответа и выведите результат.

   2.3. Игра "Переверни текст". Запросить у пользователя текст. Перевернуть введенный текст. Вывести перевернутый текст.

   2.4. Игра "Камень, ножницы, бумага". Запросить у пользователя его выбор (камень, ножницы, бумага). Сгенерировать случайный выбор компьютера. Определить победителя и вывести результат.

   2.5. Игра "Простая викторина". Создать несколько вопросов и вариантов ответов. Запросить у пользователя ответы на каждый вопрос. Подсчитать и вывести количество правильных ответов.

   2.6. Игра "Генератор случайных цветов". Создать кнопку для изменения цвета. При каждом клике на кнопку изменять цвет фона страницы (можно выбрать любой другой элемент) на случайный цвет.

## Самостоятельные модификации задания
Было решено добавить всплывающее окно, в котором написана инструкция к игре. Вместо функций prompt и alert сделано диалоговое окно в виде чата с полем ввода и кнопкой отправки текста (так же можно использовать для отправки ENTER).
Для этого используются свойства style и innerHTML. 

В игре "Камень, ножницы, бумага" выбор пользователя делается путём выбора соответствующего изображения в карусели. Для создания карусели использовались CSS свойства transition и transform. Имитация бесконечной карусели делалась путём мгновенного перехода к начальному элементу при достижении конца. Выбор элемента производится как курсором мыши, так и стрелками или пальцем в случае сенсорного экрана.
